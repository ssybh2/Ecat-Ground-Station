# 加载已有工作空间

在 **从站与任务** 或 **执行器调试** 点击 **加载已有工作空间…**，选择 EtherCAT 工作空间根目录。读取 `src/soem_bringup/config/config.yaml`，同时更新两个页面中的真实 SN、任务参数和 ROS 话题；加载后可以继续编辑，也可以连接后打开独立调试窗口。

任务始终以当前源 YAML 为准，旧工程快照只补充 Large PDO 型号、ROS Domain 等元数据。支持读取 launch 中以字面量填写的网口和 CPU 参数，读取过程不执行 Python。没有使用过本软件的标准 soem_bringup 工作空间也可以加载。

加载不会写入或编译。修改后通过 **应用任务修改** 写回所选工作空间，再点击 **colcon build**，重新启动主站。若源配置与安装配置不同，加载时会提示。动态 launch 表达式需要核对；任务导入时的默认值、PDO 重排等兼容提示也会显示。

调试连接或后台任务进行中不能切换工作空间；未保存修改可以先保存、放弃或取消切换。原 **选择工作空间…** 已更名为 **关联写入工作空间…**，仅切换写入位置、保留当前任务。
